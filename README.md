# ルルとおしゃべり

子ども向けの、スマートフォンで使える音声会話ページです。ElevenLabs Agents の WebRTC セッションを使い、ボタンを押すだけでオリジナルキャラクター「ルル」と日本語で会話できます。

## 機能

- iPhone 向けの全画面インターフェース
- リアルタイム音声会話
- 聞き取り中・発話中・接続中の表示
- マイクのミュートと通話終了
- 保護者向けの注意事項
- OS の「視差効果を減らす」設定への対応

## 開発

```bash
npm install
npm run dev
```

本番ビルド：

```bash
npm run build
```

## ElevenLabs Agent

`src/main.js` の `AGENT_ID` を、自分の公開設定済み ElevenLabs Agent ID に変更してください。秘密鍵をブラウザへ埋め込まないでください。非公開 Agent を使う場合は、サーバー側で署名付き URL を発行する構成が必要です。

## 安全について

このページは保護者の見守りのもとで使うことを想定しています。氏名、住所、学校・園、電話番号などの個人情報を話さないようにしてください。音声や会話内容は、利用する音声・AIサービスによって処理または保存される場合があります。

## キャラクターについて

ルルは非公式のオリジナルキャラクターです。既存のキャラクターやサービスとの公式な関係はありません。
